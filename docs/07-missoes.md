# 07 — Sistema de Missões

> Estrutura de progressão de **Cidade do Caos: Mundo Aberto**. Missões em **São Genésio** com protagonistas, facções e atributos da [Bíblia do Mundo](00-biblia-do-mundo.md). Eventos que disparam missões em [06-eventos-aleatorios.md](06-eventos-aleatorios.md).

## 7.1 Tipos de Missão (comparativo)

| Tipo | Prefixo | Duração | Recompensa típica | Repetível | Dada por |
|---|---|---|---|---|---|
| **Principais** | M | 8–20 min | R$ 300–2.000 + XP + história | Não | NPCs da história |
| **Secundárias** | S | 5–12 min | R$ 80–400 + XP | Algumas sim | NPCs/fofoca/eventos |
| **De Facção** | F | 10–25 min | R$ + Rep(facção) + itens | Sim (rota) | Líder de facção |
| **Diárias** | D | 3–8 min | R$ 40–200 + XP | Sim (1×/dia) | App no celular |
| **Geradas por IA** | G | 5–15 min | R$ variável (balanceada) | Sim | Sistema |

## 7.6 Missões Geradas por IA (G-)

> Missões **procedurais/geradas por IA** para conteúdo infinito após o fim do arco principal. O "IA" aqui = **sistema procedural com LLM opcional** para variação de texto/diálogo (não geração de lógica nova em runtime por segurança). Explicação completa do pipeline técnico em [12-tecnologia-implementacao.md](12-tecnologia-implementacao.md).

### Pipeline de geração

```
[1] ENTRADAS (estado do mundo)
   bairro_atual, reputação_por_facção, reputação_por_bairro,
   Nível_de_Caos, histórico_de_missões, dinheiro, atributos,
   NPCs_disponíveis, hora/clima
              │
              ▼
[2] SELEÇÃO DE TEMPLATE  (pesos por entradas)
   ex.: "entrega_tempo", "furtiv_follow", "sabotagem", "ajuda_civil",
        "racha_aposta", "investigação", "escolta"
              │
              ▼
[3] PARAMETRIZAÇÃO
   preenche: dador (NPC), alvo, local(A,B,C), item, prazo(min),
   quantidade, facção_envolvida, risco
              │
              ▼
[4] VALIDAÇÃO DE VIABILIDADE
   - local acessível agora? (não alagado/bloqueado)
   - NPC vivo/disponível?
   - pré-requisitos ok?  → se falhar, re-sortear
              │
              ▼
[5] BALANCEAMENTO DE RECOMPENSA
   recompensa = base(template) × dif(risco) × (1 + Caos/200)
   caps: R$ min/max por etapa de progressão
              │
              ▼
[6] (OPCIONAL) LLM — só texto/diálogo
   gera saudação, contexto narrativo e falas; NUNCA mecânica/valores.
   Fallback de templates estáticos se offline.
              │
              ▼
[7] ENTREGA  →  celular do jogador (notificação), marcador no mapa
```

### Templates de exemplo (G01–G06)

| ID | Template | Objetivo típico | Risco | Recompensa |
|---|---|---|---|---|
| G01 | **entrega_tempo** | Levar item de A→B em X min | Trânsito/clima | R$ 80–250 |
| G02 | **furtiv_follow** | Seguir NPC sem ser visto Y seg | Detecção | R$ 100–300 + Rep Civil |
| G03 | **coleta_sucata** | Pegar N itens em locais (gambiarras) | Baixo | R$ 60–150 + materiais |
| G04 | **racha_aposta** | Vencer corrida vs gerado | Apostar R$ | R$ aposta ×2 ou − |
| G05 | **ajuda_civil** | Resolver mini-evento para um NPC | Baixo | R$ 50–120 + Rep bairro |
| G06 | **sabotagem_facção** | Prejudicar facção rival (rep ≤ −30) | ⭐ 2 | R$ 200–400 + Rep facção |

### Regras e limites
- **Frequência:** máximo 3 G- ativas simultaneamente.
- **Coerência:** nunca pedir impossível (ex.: "levar carga" em bairro em guerra total).
- **Segurança:** LLM só escreve prosa; lógica e recompensas vêm de templates determinísticos validados. Conteúdo filtrado (manter 14+, sem sátira ofensiva).
- **Anti-grind:** recompensa com **diminishing returns** se o mesmo template repetir em sequência.

## 7.7 Estrutura de Dados de uma Missão

Modelo canônico (ScriptableObject no Unity, ver [12](12-tecnologia-implementacao.md)):

```jsonc
{
  "id": "M05",
  "tipo": "Principal",
  "titulo": "O Caminhoneiro",
  "dador": "Seu_Otacilio",
  "preRequisitos": ["M04.completa", "rep_caminhoneiros >= -50"],
  "faccao": "Caminhoneiros",
  "objetivos": [
    { "tipo": "ir",      "local": "Polo_Monte_Verde_Galpao3", "marcador": true },
    { "tipo": "coletar", "alvo": "Carga_Cimento", "qtd": 1 },
    { "tipo": "levar",   "de": "Galpao3", "para": "Centro_Obra", "veiculo_requerido": "Caminhao" },
    { "tipo": "baliza",  "local": "Centro_Obra", "tolerancia_seg": 60 }
  ],
  "recompensas": { "rs": 200, "xp": 120, "rep": { "Caminhoneiros": 10 }, "desbloqueia": ["Oficina", "F1-01"] },
  "falha": { "carga_destruida": "reinicia_objetivo", "prazo_excedido": "recompensa_50pct" },
  "repetivel": false,
  "flags": ["historia_ato1"],
  "descricao": "Seu Otacílio te chama pra buscar uma carga..."
}
```

**Tipos de objetivo compostos:** `ir → coletar → levar → entregar`, com variações `esperar`, `proteger`, `seguir(furtivo)`, `destruir`, `falar`, `minigame`, `baliza`, `chegar_em_tempo`.

## 7.8 Progressão e Dificuldade

- **XP por missão** sobe nível do personagem (habilidades, ver [03](03-personagens.md)).
- **Escalonamento:** inimigos/tempo/carga escalam com nível e Nível de Caos.
- **Repetíveis (F/D/G)** têm tetos diários para evitar inflação de dinheiro (o IPC-Caos também corrige, ver [05](05-sistemas-jogo.md)).
